Horizon Student Information System Prototype

Software Engineering Practicum

This repository contains the prototype developed for the Software Engineering Practicum. The proposed system is an integrated Student Information System for Horizon Private Training College.

Project Overview

Horizon Private Training College currently experiences challenges caused by manual and disconnected administrative processes. The prototype demonstrates how an integrated Student Information System could provide a central platform for managing student information, applications, enrolments, fee accounts, academic results, course information, communication, and management reporting.

The project is a front-end prototype and is intended to demonstrate the proposed user interfaces and user interaction. No database or backend implementation is included.

Functional Areas

The prototype demonstrates the following functionality:

- Student record management
- Online student applications
- Course enrolment management
- Student fee and balance management
- Outstanding fee notifications
- Course materials and schedule access
- Academic announcements and notifications
- Assessment results and academic progress
- Academic and enrolment reporting
- User authentication and role-based access concepts

Prototype Functionality

JavaScript is used to provide controlled front-end prototype functionality, including:

- Student record searching
- Student status filtering
- Fee reminder interaction
- Payment confirmation
- Management report selection
- Announcement interaction
- Navigation highlighting

These functions demonstrate user interaction only and do not connect to a database or external backend service.

Purpose

The purpose of this prototype is to illustrate how users could interact with the proposed Horizon Student Information System and how the system could address the administrative and academic requirements identified during the software requirements and design process.
